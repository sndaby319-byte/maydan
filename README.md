# ميدان التركيز

مسابقات حلقة عمر بن عبد العزيز (المرحلة الثانوية): مسابقة الحلقة، وتحدّي العشرة، ومن سيربح ١٠٠، وخريطة المصحف، وغيرها.

يعمل على الجوال واللابتوب، ودون إنترنت بعد أول فتح. افتحه في المتصفح، ثم اختر «إضافة إلى الشاشة الرئيسية».

أسماء الطلاب ونقاطهم تُحفظ في الجهاز نفسه فقط، ولا تُرفع إلى أي مكان.
